Hurdle 1: Robot Navigation Project
A Python-based robot navigation project created using the Reeborg’s World simulation platform. In this challenge, the robot autonomously navigates through multiple hurdles by following programmed movement instructions and successfully reaches the destination.

🚀 Features
- Autonomous robot movement
- Hurdle detection and traversal
- Grid-based navigation system
- Python-controlled movement logic

📌 Project Description
This project solves the Hurdle 1 challenge from Reeborg’s World, where the robot must move across a path containing obstacles (hurdles) and reach the finish point successfully.

The robot is programmed using Python commands to:
- move forward,
- change direction,
- avoid obstacles,
- and navigate efficiently through the environment.
